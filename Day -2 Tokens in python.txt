6. Comments:-
-----> once comments are open the lines inside will never execute in python file

Two types:- 1. Single line comment (#)

1.Single line comment:- Used to comment only one line

Example:-

if age >= 18:  #this check age is grater or equal
    print(age)
 

2. Multi - line comment('''  ''',  '' '' ''   '' ''  '')
---------> used to comment more than one line
