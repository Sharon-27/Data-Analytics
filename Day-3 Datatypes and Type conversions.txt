	1. Numeric Datatype:-
Definition:- Float and integers is called as numeric datatype

1)Float
Definition:- A number which contains decimal values we call it as a float datatype
Example:- 56.89 (price)

2)Integer (int)
Definition:- A normal value without any decimal values
Example:- num = 89
          num_2 = 6


2. String:-

Definition:- String is a sequence of character that are enclosed in single quotes-', double quotes-", """" ( use only for commenting purpose)
----> String is immutable

Example:-
any_ = 'python is a language'

all_ = 'Ab,.&[)-+'


3. List:-

Definition:- List is a collection of different Datatypes and it is represented by square braces.[] that are separated by comma (,) and inside the lists we call it as items.
------> List is mutable

Example:- any_ =[1,'python',(5,6)]
          print(type(any_))


4. Tuple:-

Definition:- Tuple is a collection of different datatypes that are enclosed with parenthesis() and those are separated by commas---,
-------> Tuple is immutable

Example:- nums = (1, 89.67,'python'.[3,4],(8,9))


5. Dictionary:-

Definition:- Dictionary is collection of key:value pairs keys and values are separated by :---(colon)
--> Key and value pair is call it as a item
--> Items are separated by comma ,
--> Dictionary is represent by using {} Curly braces
--> In key place we can use immutable datatypes
--> In values place we can use any datatype

Example:- 
-->
data_ ={1:2
        'name':'Teja',
         (2,3) :'tuple'}
print(data_)


6.Set:-

Definition:-Set is a collection of unique elements and set can't allow any duplicate values inside it
--> Set is represented by curly braces{} and the elements are separated by commas ,

Example:- 
an = {1,2,3}
print(an)
